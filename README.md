# Advanced Deep Learning Labs (index)

The five labs from *Advanced Deep Learning (D7047E)*, Luleå University of Technology, now each live in their own repository with a dedicated README and results:

| Lab | Repository | Topic |
|---|---|---|
| 0 | [cnn-transfer-learning](https://github.com/amerbarood/cnn-transfer-learning) | CNNs on CIFAR-10, AlexNet fine-tuning, MNIST → SVHN transfer |
| 1 | [nlp-gpt-and-sentiment](https://github.com/amerbarood/nlp-gpt-and-sentiment) | Character-level GPT from scratch, sentiment chatbot |
| 2 | [gans-and-diffusion-models](https://github.com/amerbarood/gans-and-diffusion-models) | GANs, adversarial examples, score-based diffusion |
| 3 | [image-captioning-cnn-lstm](https://github.com/amerbarood/image-captioning-cnn-lstm) | VGG16 + LSTM image captioning on Flickr8k |
| 4 | [dqn-atari-breakout](https://github.com/amerbarood/dqn-atari-breakout) | Deep Q-learning on Breakout, hyperparameter study |

The course project from the same group is [nordic-vehicle-detection](https://github.com/amerbarood/nordic-vehicle-detection).

Each lab repository is a runnable Python project for VS Code: a package with a `main.py` command-line entry point, `requirements.txt`, `.vscode` launch configurations and smoke tests; see the "Running the code" section of each README.

The original notebooks have been retired; the full history, including the notebooks, is in [Gabmyr/D7047E-Labs-Group-7](https://github.com/Gabmyr/D7047E-Labs-Group-7).
